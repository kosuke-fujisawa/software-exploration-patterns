## 書くときの注意

- **他者の著作物の本文を転載しないでください。** このリポジトリは [CC0 1.0](https://github.com/kosuke-fujisawa/software-exploration-patterns/blob/main/LICENSE) ですが、CC0 は第三者の著作物には及びません
- 書くのは、書誌情報・公式リンク・**あなた自身の言葉による要約**です
- 短い引用をする場合は、出典を明示し、引用の範囲にとどめてください
- 内容をよく知らないが存在は知っている、という段階でも構いません。その場合は `status: stub` にして、分かっている範囲だけを書いてください。詳しい人が後から埋めます
