# 0003 コンテンツのライセンスを CC0 1.0 とする

- 状態: Accepted
- 日付: 2026-10-04

## 背景

この知識ベースは、再利用・継承されることを目的としている。また「特定個人がいなくなっても知識が残る」ことを設計目標にしている。リポジトリ作成時点で [CC0 1.0 Universal](https://github.com/kosuke-fujisawa/software-exploration-patterns/blob/main/LICENSE) が設定されていた。

## 決定

**CC0 1.0 Universal を継続する。** コンテンツとスクリプトを分離せず、リポジトリ全体を CC0 1.0 とする。

## 比較

| ライセンス | 利点 | 欠点 |
|---|---|---|
| **CC0 1.0**（採用） | 再利用の摩擦が最小。書籍・社内資料・他の知識ベース・学習データなど、どこにでも取り込める。ライセンス上の理由で知識が行き止まりにならない | 出典表示の義務がない。派生物がクローズドになりうる |
| CC BY 4.0 | 表示義務により出所が辿れる。普及に有利 | 派生物がクローズドなまま再公開されうる。表示義務が社内利用時の摩擦になることがある |
| CC BY-SA 4.0 | 継承により、派生した知識も open に保たれる | CC BY-SA でない媒体（書籍、他ライセンスの Wiki、社内文書）への取り込みが難しくなる。知識の伝播そのものを妨げうる |

「知識が生き残ること」を「出所が辿れること」より優先し、最も摩擦の少ない CC0 を選んだ。

## 帰結

- **誰でも、許諾や表示なしに、Fork・改変・再配布できる。** Maintainer 不在でも、ライセンス上の障害なく継続できる（[GOVERNANCE.md](../../GOVERNANCE.md)）
- **ライセンス上の義務がないことと、出典を書かないことは別の話である。** 知識の追跡可能性のために出典を残す文化を、[CONTRIBUTING.md](../../CONTRIBUTING.md) で明示的に求める
- **CC0 は第三者の著作物には及ばない。** 他者の文章の転載を禁止し、`sources/` には書誌情報・リンク・自分の言葉による要約のみを書くルールとする
- 投稿者には、投稿内容が CC0 1.0 で公開されることへの同意を求める（CONTRIBUTING に明記）
- スクリプトも CC0 とする。知識ベースに付随する小規模なツールであり、ライセンスを分離する実益より、全体が1ライセンスである分かりやすさを優先した

## 補足

この決定は変更しうるが、**遡及的な変更は難しい**。CC0 で受け取った貢献を後からより制限的なライセンスに変えることはできないため、変更する場合は、変更日以降の貢献に対してのみ適用するなどの手当てが必要になる。
