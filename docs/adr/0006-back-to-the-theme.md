# 0006 テーマに戻し、足す表示を最小限にする

- 状態: Accepted
- 日付: 2026-10-04
- 関連: [0005 表示は自前の最小レイアウトで行う](0005-minimal-custom-layout.md) を置き換える

## 背景

ADR 0005 で gem テーマの利用をやめ、レイアウト2枚と CSS 1枚を自前で持つことにした。狙いは front matter の情報（status / tags / related / sources / episodes）を表示に出すことだったが、実際に作ったものは、

- トップページのヒーローと色付きのボタン
- カードグリッド
- ピル型のバッジとタグ
- 色付きの囲み（note）
- ダークモード対応

まで広がった。結果として、**知識ベースらしい素朴な見た目から離れ、「よくある生成物」のような体裁になった**。これはこのプロジェクトの性格と合わない。ここに置くのは検証されていない途中の知識であり、見た目が整っていることは内容の確からしさを意味しない。装飾は、むしろ誤解を生む。

サイトの作り込みは、このリポジトリの優先順位（1. 保守しやすい、2. Markdown が Source of Truth）より下にあるはずだった。

## 決定

**テーマ（`jekyll-theme-primer`）に戻す。** 自前の `_layouts/default.html` と `assets/css/main.css` は削除する。

足すのは `_layouts/knowledge.html` 1枚だけとし、その中身も次に限る。

- 本文の前: 分類へのリンクと `status`（draft なら「検証中」と分かる表記）
- 本文の後: `tags` へのリンクと、意見を送る・編集する・Markdown 原文へのリンク

`related` / `sources` / `episodes` はテンプレートで一覧にしない。本文側に
「なぜ関連するのか」を添えて書いてあり、テンプレートで出すと同じリンクが
2回並ぶだけになるため。front matter の値は `catalog.json` 側で機械可読に保つ。

**CSS は書かない。** カード、ボタン、バッジ、色付きの囲みを使わない。表示はテーマの素の Markdown スタイル（GitHub の README と同じ見た目）に任せる。

トップページを README と分けること自体（`index.md`）は維持する。これは見た目ではなく、**初めて来た人が何のサイトか分かり、パターンを1つ読み、自分も投稿できると分かる**という導線の問題であり、ADR 0005 とは別の判断だった。ただしその中身も、見出しと箇条書きだけのプレーンな Markdown で書く。

## 理由

- 素朴な見た目のほうが、「検証されていない途中の知識が置いてある場所」という性格を正しく伝える
- 自前 CSS を持たなければ、見た目の保守は発生しない。テーマの更新に乗れる
- 導線の改善（短い説明、代表パターン、投稿への入口、分類の説明）は、装飾ではなく**文章と並び順**で達成できる
- JavaScript は引き続き使わない

## 帰結

- ダークモード対応はなくなる（テーマが light のみ）
- ナビゲーションバーはなくなる。各ページ上部のサイト名がトップへのリンクになり、分類の行き来は本文中のリンクで行う
- `_data/catalog.json` をビルド時に生成してテンプレートから id を引く仕組みは維持する。これは見た目ではなく、**HTML 側に知識を書き写さない**ための仕組み（ADR 0001）
- 表示に出すのは front matter にある情報だけ、という方針（ADR 0005 から引き継ぎ）は維持する
